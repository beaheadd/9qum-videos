# 9qum — видеоуроки Эльдара

Курс «Тогызкумалак с нуля» — 24 урока на трёх языках (ru, en, kk). Видео 720×1280 (9:16, H.264 + AAC, faststart — можно сразу встраивать в `<video>`), обложки 720×1280 JPG.

- `togyz/<lang>/<NN>.mp4` — урок NN (01…24), `<lang>` = `ru` | `en` | `kk`
- `togyz/<lang>/<NN>.jpg` — обложка (poster)
- `videos.json` — список всех уроков: язык, номер, `lesson_id` (как в программе курса на сайте: board, sow, tuzdyk…), модуль, название, описание, длительность, прямые ссылки `video_url` и `cover_url`

Прямая ссылка: `https://raw.githubusercontent.com/beaheadd/9qum-videos/main/togyz/ru/01.mp4`
